# Mneme Space Combat — Actions and Reactions

> **Source:** Mneme Variant Space Combat Rules v2.45

---

## 1. Action and Reaction Limits

There are limits to the number of Non-Player Characters that can take **Functions** in Mneme Space Combat. The game mechanics are designed to provide the Referee options to consolidate Functions so that the Referee rolls less and has lower overhead.

### Turn Duration

Each turn in space combat lasts around **one kilosecond (1,000 seconds)** of game time (or roughly 17 minutes).

In a combat turn, vessels have **individual Initiative**.

A character's **Function** determines:
- When they get to act during their ship's turn
- The sort of actions they can do
- What they can react to

---

## 2. Action Types

### Minor Action (MA)

The most basic unit of Action in Space Combat. Each turn has **3 Minor Actions** (and 1 reaction for the Non-Automated Major Functions).

### Significant Action (SA)

A significant action costs **Two Minor Actions**. These are the most common actions that have a great impact in the game.

### Focused Action (FA)

A type of action where **all 3 Actions and Reactions are spent** to ensure a better chance of success.

- Any Significant Action can be turned into a Focused Action
- Trade-off: **no Reactions can be made** and all 3 Minor Actions are spent
- This grants **DM+2** to the Action
- Can also be called **Full Action**
- After taking a Focused Action, characters cannot make any reactions
- Characters who made reactions in that turn cannot use Focused Actions

### Reactions (RA)

1. During a combat turn, a character can only make **one reaction without any penalty**
2. Any additional reactions (either through Preparation or Sacrificing Initiative) incur a **cumulative penalty of DM-1** for each extra reaction
   - Second reaction: DM-1
   - Third reaction: DM-2
   - etc.
3. Opposing an Adversary's Roll consumes a **Reaction or Minor Action**
   - Example: Range Check is an Opposed Roll — if the other party decides not to oppose, they don't lose a Minor Action or reaction, but the party performing the Range Check does it at a lower difficulty
4. When reactions are used to Oppose a Roll, the DM penalty or Bonus applies to the roll or the TN
   - Example: Significant Prepare to Oppose a Roll gives DM+1 or DM+2 if done to augment a Reaction

#### Extra Reactions

Extra reactions can be obtained in the following ways:

**a. Sacrifice Initiative Reaction**
- Commanders can sacrifice **2 initiative points** to grant a character an additional reaction
- Additional reactions have the cumulative DM-1 penalty
- Typically given to NavComm (to oppose sensor locks and jamming) and Gunner crew (for point defense)

**b. Prepare, Minor**
- Spend a Minor Action to prepare a reaction
- Grants DM+1 to the prepared reaction

**c. Prepare, Significant**
- Spend a Significant Action (2 MA) to prepare a reaction
- Grants DM+2 to the prepared reaction

## 3. Major Functions and Action Limits

Major Functions are best saved for PCs and key NPCs.

The Referee can only juggle so many NPCs. To speed up play, Major Function NPCs are considered using their reactions to oppose the PC's rolls.

There should be a **maximum of Major Functions as 2× the PCs** (reflecting NPCs who will be opposing them).

If there are **fewer Major Function NPCs**, they will:
- Use the extra reaction mechanics (sacrificing Initiative)
- Convert all their Actions to Reactions
- Upgrade an Assistant Function NPC to a Major Function to oppose

### Leading a Function

In every function (Sensor, Navigation, Engineering, Gunner, Piloting), there is always a designated **"lead character"** responsible for making the primary roll or action.

- **Standard Rule:** Only one roll or action is made per function
- Other NPCs in the same function can assist the lead character but do not make separate rolls
- **Exception — Player Characters:** If there are multiple PCs in the same function, each may perform additional actions
- **Squadron Rule — NPCs:** In a squadron, only one roll is made for each function. NPCs serve to raise the stakes and difficulty but do not require separate rolls

## 4. Types of Functions

| Function Type | Function | Description |
|---------------|----------|-------------|
| **Major** | Captain | Leads the ship and crew. Only 1 per ship. Can manage up to 5 crew without penalty; -1 per additional 5. Captain's Assistants divide penalty. |
| **Major** | NavComm | In charge of Sensors and Electronic Transmissions. Multiple allowed, up to the number of Sensor/Comms Stations or Sensors (whichever is lower). |
| **Major** | Engineer | Keeps ship systems running. Any number. 1 Engineering Station per 3.5 DT of Drives and Powerplant. |
| **Major** | Pilot | Flies the ship. Only 1 per ship. |
| **Major** | Gunner | Up to number of FireControl Systems and available Bridge Stations (whichever is lower). |
| **Assistant** | Captain's Assistant | Assists the captain. Occupies a bridge station. Needs Leadership 0. |
| **Assistant** | Copilot | Assists piloting. Any number, as long as Bridge Stations available. |
| **Assistant** | NavComm Assistant | Assists NavComm. Any number, as long as Bridge Stations and Sensors available. |
| N/A | Passenger | Anyone else. |

## 5. Function Phases and the Space Combat Turn

Ships act in initiative order. Within each ship's turn, characters act in this order:

### Phase 1: Captain (Significant Actions)

| Action | Description |
|--------|-------------|
| **Command** | Issue orders to crew |
| **Coordinate** | Coordinate crew actions (grants DM+1 per effect to next crew action) |
| **Inspire** | Boost crew morale/performance |
| **Lead** | Lead by example |
| **Rush** | Sacrifice initiative to grant extra reactions |

### Phase 2: NavComm (Significant Actions)

| Action | Description |
|--------|-------------|
| **Secure System** | Protect ship systems from EW |
| **Jam Signal** | Jam enemy communications/sensors |
| **Break Target Lock** | Break enemy sensor lock |
| **Plot Jump Point** | Calculate jump coordinates |
| **Sensor Lock** | Lock sensors onto target |
| **Range Check** | Determine exact range to target (opposed roll) |
| **Directed Scan** | Focused sensor sweep |
| **Hack System** | Attempt to hack enemy systems |

**NavComm Minor Actions:**
- **Scan** — General sensor sweep
- **Communicate** — Send/receive transmissions
- **Comms/Sensor Black-out** — Go silent

### Phase 3: Engineer (Significant Actions)

| Action | Description |
|--------|-------------|
| **Activate Jump** | Prepare and execute jump |
| **Work Around** | Bypass damaged systems |
| **Go Dark** | Reduce EM signature |
| **Start up** | Bring offline systems online |
| **Optimize** | Improve system performance |
| **Red Line** | Push systems beyond safe limits |

### Phase 4: Pilot (Significant Actions)

| Action | Description |
|--------|-------------|
| **Evade** | Evasive maneuvers (opposed roll vs gunner) |
| **Attack Run** | Maneuver for optimal attack position |
| **Dock/Land** | Approach and dock with target/station |
| **Ram** | Intentional collision |
| **Full Burn** | Maximum thrust maneuver |

**Pilot Conditions — Ballistic**
- A ship that is not actively piloted (no pilot action) goes **ballistic**
- Ballistic ships cannot dodge or maneuver

**Pilot Minor Action:**
- **Maneuver** — Adjust position/speed

### Phase 5: Gunner (Significant Actions)

| Action | Description |
|--------|-------------|
| **Direct Attack** | Fire weapons at target |
| **Direct Attack Group Option** | Group all direct fire weapons into one MAC roll |
| **Control Missile/Drone** | Guide missiles/drones |
| **Launch/Maneuver Missiles/Drone** | Deploy missiles or drones |
| **Go Ballistic Option** | Let missiles go unguided (simpler but less accurate) |
| **Missile/Drone Attack** | Resolve missile/drone attack |
| **Missile Attack Group Option** | Group missile attacks into one MAC roll |
| **Proximity Explosion Option** | Detonate missiles at range for area effect |
| **Missile/Drone Ram Option** | Ram target with missile/drone |

### Phase 6: Everyone Else

| Action | Description |
|--------|-------------|
| **Delay** | Hold action for later in turn |
| **Instruct Automated Function** | Command automated systems |
| **Take Function** | Assume a function not currently occupied |

## 6. Reactions List

Reactions can be taken when triggered, consuming the character's reaction for the turn.

| Reaction | Function | Trigger | Effect |
|----------|----------|---------|--------|
| **Initiative for Reaction** | Captain | Any time | Sacrifice 2 initiative to grant someone an extra reaction |
| **Aiding Another** | Any | Ally making a roll | Assist ally's roll (typically DM+1) |
| **Opposing a Roll** | Any | Adversary making a roll | Oppose with own skill (consumes reaction) |
| **Point Defense** | Gunner | Missile/drone attack incoming | Roll to shoot down missiles/drones |
| **Cast Sand** | Gunner | Beam attack incoming | Deploy sandcaster defense |
| **Dodge** | Pilot | Attack incoming | Roll to evade (opposed vs gunner) |
| **Go Ballistic** | Pilot | Any | Ship goes ballistic (no maneuver next turn, but may avoid damage) |
| **Damage Control** | Engineer | System damaged | Roll to repair/restore damaged system |
| **Manage Morale** | Captain | Crew morale event | Roll to maintain crew effectiveness |
